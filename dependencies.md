# Build dependencies

This document lists the applications and libraries needed to build to-stations-proto on Windows x64. It includes direct build inputs and their transitive dependencies. It is a snapshot of the build dependency graph; pinned component versions and install locations remain in [docs/versions.md](docs/versions.md).

## How to read this document

- **Direct** means a dependency declared by a repository application, library, or build script.
- **Transitive** means a dependency required by another dependency rather than directly by this repository.
- **Size** is an approximate download, installed, or source-tree size for the version listed. System-tool sizes depend on the selected installer workload and are not additive.
- Rust package sizes are `.crate` download sizes from the local Cargo cache. The four pinned CycloneDDS-Rust git packages share one checkout; their size is shown as a shared checkout.
- Standard Windows OS DLLs are not listed individually. Runtime-only prerequisites are listed in the final section.
- Snapshot date: 2026-11-25.

- An Xbox-style game controller for physical-controller testing of `paws`; Virtual mode needs only a mouse.
